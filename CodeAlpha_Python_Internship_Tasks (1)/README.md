# CodeAlpha Python Programming Internship Tasks

This repository contains four beginner-friendly Python projects based on the supplied CodeAlpha task list.

## Projects
1. `Hangman_Game/hangman.py` — console Hangman game with five predefined words and six incorrect guesses.
2. `Stock_Portfolio_Tracker/stock_tracker.py` — calculates investment value from a hardcoded sample price dictionary and user-entered quantities.
3. `Task_Automation/email_extractor.py` — extracts email addresses from a text file and writes them to another file.
4. `Basic_Chatbot/chatbot.py` — simple rule-based chatbot.

## Requirements
- Python 3.8 or newer
- No third-party packages required

## Run a project
Open a terminal in the relevant project folder and run, for example:

```bash
python hangman.py
```

For the email extractor, create `input.txt` in the same folder and add text containing email addresses, then run:

```bash
python email_extractor.py
```
