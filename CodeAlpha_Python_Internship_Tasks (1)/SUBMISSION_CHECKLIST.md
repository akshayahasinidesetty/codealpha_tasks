# Before submitting

- [ ] Run each script and test normal and invalid input.
- [ ] Choose at least two tasks (or follow the exact requirement in your internship message/form).
- [ ] Create a separate public GitHub repository for each selected task using the required `CodeAlpha_ProjectName` naming pattern.
- [ ] Upload the source code and a short README to each repository.
- [ ] Record a short screen/video explanation showing the program running; post it on LinkedIn if required.
- [ ] Tag the official CodeAlpha account as requested in the internship instructions.
- [ ] Submit the GitHub links using the submission form shared by your internship group.
- [ ] Do not upload passwords, API keys, personal information, or private files.
